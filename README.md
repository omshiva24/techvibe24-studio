# TechVibe24 Studio

Build pipeline for TechVibe24 YouTube videos by P Om Shiva, M.Tech CSE (2nd year), Pondicherry University.

- `tools/scenes.py` makes candidate scene paintings and depth maps
- `tools/timeline.py` lines up the karaoke lyrics with the narration
- `www/stage2` animates each painting with 2.5D camera moves, light and particles
- `tools/render.mjs` + `tools/assemble.sh` render the final video and Shorts
